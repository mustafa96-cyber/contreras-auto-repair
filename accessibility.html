Accessibility.

We want this site to work well for everyone, so we build it with accessibility in mind. That includes semantic structure, keyboard navigation, labeled form fields, strong color contrast in both light and dark themes, and full support for reduced motion.

The 3D and animated elements pause or simplify automatically when your device requests reduced motion, and every animated element has a static fallback.

If anything on this site is hard to use, please tell Saedi Tech and it will be fixed before launch.
